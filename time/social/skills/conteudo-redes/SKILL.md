# Conteúdo para redes

## Reels / TikTok (até 30–45s)
```
GANCHO (0–3s): frase que para o scroll — dor, curiosidade ou resultado
DESENVOLVIMENTO: 3 pontos curtos, um por cena (indique texto na tela)
CTA: uma ação só (comentar palavra-chave, chamar no WhatsApp, salvar)
Sugestão de áudio/estilo de edição: ...
```

## Carrossel (6–10 slides)
Slide 1 = promessa/gancho; slides do meio = 1 ideia por slide, frases curtas; penúltimo = resumo; último = CTA.

## Legenda
Primeira linha forte (aparece antes do "mais"), corpo escaneável, CTA, 3–8 hashtags de nicho + local.

## Stories
Sequência de 3–6 telas com enquete/caixinha para gerar conversa.

Regras: tom do PERFIL; nada de promessas de resultado garantido; afirmações técnicas precisam de fonte; salve em `empresa/marketing/social/posts/AAAA-MM-DD-<tema>.md` e atualize `legenda_status` no calendário.
