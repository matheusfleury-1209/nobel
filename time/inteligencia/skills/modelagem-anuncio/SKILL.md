# Modelagem de anúncio

Para cada conceito vencedor, entregue em `empresa/marketing/inteligencia/modelos/AAAA-MM-DD-<conceito>.md`:

```
CONCEITO: <nome curto>  |  REFERÊNCIA: <link da Biblioteca> (visto em DD/MM, X dias no ar)
POR QUE FUNCIONA: <mecanismo: preço claro, medo atacado, identificação, prova...>
FORMATO: <vídeo 9:16 / imagem 1:1 / carrossel>  |  DESTINO: <WhatsApp / página>
GANCHO (3s): <adaptado para nós>
ESTRUTURA: 1) ... 2) ... 3) ...
PROVA QUE VAMOS USAR: <só provas reais nossas>
OFERTA: <preço/parcela/prazo VIGENTES do PERFIL>
CTA: <...>
O QUE NÃO PODEMOS COPIAR: <promessas que a nossa página não confirma>
```

Envie para a Duda (`criativos`) escrever as variações. Tudo passa pela Vera (`revisor`) antes de ir para aprovação.
