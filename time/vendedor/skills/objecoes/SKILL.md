# Contorno de objeções

Método: **acolher → entender → responder → confirmar**. Nunca discuta, nunca pressione.

- **"Está caro"** → "Entendo. Caro comparado a quê?" Mostre valor/retorno, ofereça plano menor ou parcelamento **do PERFIL**. Desconto extra só com aprovação.
- **"Vou pensar"** → "Claro! Ficou alguma dúvida que eu possa esclarecer agora?" Combine data do retorno.
- **"Preciso falar com meu sócio/esposa"** → ofereça um resumo para encaminhar ou uma conversa com os dois.
- **"Já tenho fornecedor"** → pergunte o que gostaria que fosse melhor; mostre diferencial real.
- **"Agora não é o momento"** → pergunte quando faz sentido e agende o follow-up para lá.
- **"Funciona mesmo?"** → provas reais do PERFIL (cases, garantia). Nunca invente.

Registre a objeção em `observacoes` do lead — o `criativos` e o `trafego` usam isso para melhorar anúncios.
