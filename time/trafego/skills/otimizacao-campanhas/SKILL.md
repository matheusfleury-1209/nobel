# Otimização de campanhas

Regras práticas (ajuste pelas metas do PERFIL):
- Não julgue conjunto com menos de ~1.000 impressões ou investimento < 2× o CPL meta.
- CPA > 1,5× a meta por 3 dias seguidos → propor pausar ou trocar criativo.
- CPA < meta e frequência < 3 → propor escalar 20–30% (nunca dobrar de uma vez).
- CTR baixo (< 0,8% feed Meta) → problema de criativo/copy: peça novas variações ao `criativos`.
- CTR bom e conversão ruim → problema de página/oferta/atendimento: avise a Diretora e o `vendedor`.
- Frequência > 3,5 → público saturado: propor público novo ou criativo novo.

Saída: lista de ações com impacto estimado e custo. Cada ação que mexe em dinheiro vira um bloco em `empresa/aprovacoes/pendentes.md`. Depois de aprovado, descreva o passo a passo exato para o dono (ou para quem tem acesso) aplicar no gerenciador — ou aplique via API se a integração estiver configurada e a aprovação disser isso.
