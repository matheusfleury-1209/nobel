# Auditoria de conversas

1. Pegue as últimas 20–50 conversas sem venda (exportação do WhatsApp, prints enviados pelo Matheus/Hanielly ou o CRM).
2. Para cada uma, marque:
   - tempo até a 1ª resposta
   - em que etapa parou (saudação / qualificação / estágio / preço / link enviado / sumiu)
   - objeção dita ou provável
   - se recebeu follow-up
3. Monte a tabela de perdas por motivo (ex.: 35% "estágio", 25% "sumiu sem follow-up", 20% "preço").
4. Para os 2 maiores motivos: proponha a mudança (roteiro, prova, oferta, qualificação no anúncio) com a mensagem pronta.
5. Relatório em `empresa/melhorias/AAAA-MM-DD-auditoria-conversas.md`. Proteja dados pessoais: use só o primeiro nome.
